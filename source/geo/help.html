凸包画板 · 说明

在网页上随手放点、连线、拖拽、删除、改颜色大小的小工具，后续会加「一键画凸包」和 3D。

基本操作

操作效果
单击空白弹出小菜单：添加点 / 取消选中
单击点 A，再单击点 B在两点之间连一条边
拖动点 / 边移动；若该点/边已被选中，则整组一起移动
拖动空白按右侧面板的模式：框选 / 平移 / 旋转
右键 点 / 边弹出菜单（对选中的对象操作）
右键空白取消选中
选中后按 Del删除选中的点 / 边（Del 或 Backspace）
滚轮缩放（以鼠标位置为中心）
Esc取消选中 / 收起菜单

原点与编号

  • 画面中心有 原点 (0,0) 标记，随视图平移/旋转。
  • 每个点旁边显示它的编号；手动新建的点从 1 起自动编号，导入的点按导入时的行序编号。

左侧信息窗

  • 选中一个点：显示 编号（可改）、坐标、染色。
  • 选中一条边：显示 端点、容量（可改）、流量（可改）。
  • 多选时显示选中数量。这些字段是为以后加算法（最短路、网络流、二分图染色…）预留的。

导入（右下角按钮）

  • 点：每行 x y，编号按行序 1…n。
  • 边：每行 u v，u、v 就是上面点的编号。
  • 导入后会自动缩放到刚好装下所有点。
  • 覆盖导入 = 清空后导入；追加导入 = 加到现有画板上（新点编号接着往下排）。

右键菜单（对着 点 / 边 右键）

菜单里的所有操作都只作用于「选中的」目标。右键一个没被选中的对象，会先把它选上。

  • 求凸包：对选中的点求凸包，并把相邻顶点连成真实的边（用凸包色；同样能参与求角度）。C++ 实现。
  • 求重心：选中的点的重心，生成一个新点。C++ 实现。
  • 显示 / 隐藏角度：在选中的顶点处显示相邻两边的夹角（度 + 弧度）。
  • 删除所有边：删掉选中的边。
  • 删除所有：删掉选中的点 + 边。

右键空白则是「取消选中」。

右侧面板 · 拖动空白

  • 选中（默认）：拖动空白画一个方框，框住的点、边会被选中（边的两端都在框内才算）。
  • 平移：拖动空白平移视图。
  • 旋转：拖动空白旋转视图，以「屏幕中心」（当前可视范围中心）为轴。

顶部工具栏 · 颜色与大小

  • 四个控件：点色、点大小、边色、边粗细。
  • 没选中对象时：改的是「新对象」的默认样式 —— 之后新建的点/边就用这个颜色和大小。
  • 选中对象后：改的是选中的那些对象；可以框选多个一起统一改。
  • 控件右边的小字会显示当前作用对象：新对象 或 选中 N 点 M 边。

清空

顶部「清空」会移除所有点和边，需要二次确认，防止误触。
